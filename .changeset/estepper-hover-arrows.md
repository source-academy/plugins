e-stepper: an arrow from the program to a frame is drawn only while the frame is hovered. An arrow to an object is drawn all the time while "From program" is on, and only while the object is hovered when it is off. `onAnchors` gets a second argument `fromProgram` for this; a host that omits it behaves as before.
